350L · 65mm · 40m

높은 곳·지하 = 30(쓰리)

"단구형"이라 하면 틀린 답 → 정답은 쌍구형 		소방차 2호스 동시 연결 위해 쌍구형. "쌍둥이 65"

리타딩챔버 목적 알람밸브의 오보 방지 (비화재 시 오작동 경보 차단) 물 흐름 잠깐 지연시켜 진짜 화재인지 확인. "리타드(retard)=지연=오보컷"
포소화설비 구성 2회 구성요소 : 약제탱크 · 혼합장치 · 가압송수장치
"정압작동장치" → 속하지 않음 (정답!) (이건 분말소화설비용) 		정압작동 = 분말소화용 관막힘 방지장치. "포(泡)에는 정압 없다"
물분무 소화설비 물입자가 미세하여 전기절연성 확보 → C급(전기) 화재에 적응성 있음 "물 = 전기화재 부적합" 은 함정. 분무는 OK. "안개비는 감전 안 됨"
화재감지기 - 열/연기 구분 3회 열감지기 = 차동식 · 정온식 · 보상식
연기감지기 = 광전식 · 이온화식
→ "열감지기 아닌 것?" → 광전식 (정답) 		"광(光)·이(離)는 연기" 만 기억. "광이 = 연기"
(나머지는 다 열)
차동식 분포형 종류 2회 분포형 = 공기관식 · 열전대식 · 열반도체식
→ "분포형 아닌 것?" → 스폿식 (정답) (스폿형은 차동식이지만 분포형 아님) 		스폿=한 점, 분포=넓은 범위. "분포는 공·전·반"
보상식 감지기 차동식 + 정온식의 OR 동작 (둘 중 하나만 만족해도 작동)
"둘 다 만족해야 작동" → 틀림		 OR이지 AND가 아님. "보상은 둘 중 하나"

⚡ 2. 전기 일반 (옴·역률·법칙)

핵심 개념정답 (외울 핵심)한 줄 해설암기 팁 💡
도선 저항 공식 4회 R = ρ · l / A → 길이에 비례, 단면적에 반비례
※ "단면적에 비례 / 길이에 반비례" → 틀린 보기 (자주 출제!)
길이 ×2, 단면적 ×½ → 저항 ×4 증가 		길이↑ = 저항↑ (멀수록 힘들다) "길반(吉反)" : 길이 비례, 단면적 反비례
옴의 법칙 V=IR V=100V, I=10A → R=10Ω. V=95V 인가 → I = 9.5 A
V=220V, I=5A → R = 44 Ω		 저항이 일정하면 전압·전류는 비례. "브이는 아이알"
키르히호프 법칙 제1법칙 = 전류법칙 (한 점 들어오는 전류 = 나가는 전류)
제2법칙 = 전압법칙 (폐회로 기전력 = 전압강하 합) 		제1=전류, 제2=전압. 끝. "일전이전(一電二壓)"
쿨롱의 법칙 2회 두 전하 간 힘 = 전하 곱에 비례, 거리 제곱에 반비례 F = k·Q₁Q₂/r² "쿨하게 곱하고 제곱으로 나눠"
유효·무효·피상전력 유효전력 P = VI cosθ [W]
무효전력 = VI sinθ [Var] / 피상전력 = VI [VA]
역률 cosθ = 유효/피상 = P/√(P²+Q²) 		유효=W, 무효=Var, 피상=VA. 단위로 외움. "유W · 무Var · 피VA"
역률 계산 (P=80, Q=60) 2회 cosθ = 80 / √(80²+60²) = 80/100 = 0.8 (80%) 3:4:5 직각삼각형 트릭. "6·8·10 = 0.8"
RLC 직렬 역률 (R=30, XL=60, XC=20) 2회 cosθ = R / √(R² + (XL-XC)²) = 30/√(30²+40²) = 0.6 또 3:4:5 트릭 (30,40,50). "3·4·5 = 0.6"
소비전력 P=V²/R 2회 예) 220V·1210W → R=40Ω → 200V 사용 시 P = 200²/40 = 1000 W
예) 200V·1kW 전열기를 100V 사용 → P = 100²/40 = 250 W 		전압 ½ → 전력 ¼ (제곱이라!) "전압 반토막, 전력 네토막"
전압 변동률 2회 ε = (V무부하 − V정격) / V정격 × 100
예) (220−200)/200 = 10%		 분모는 항상 "정격(부하시)" 전압! "무빼정 나누기 정"
합성저항 (병렬 동일저항 n개) 동일 저항 R을 n개 병렬 → R/n
예) 10Ω 5개 직렬 최대 = 50Ω / 20·30Ω 병렬 = 12Ω		 병렬 = 작아짐, 직렬 = 커짐. "병작직커"
콘덴서 정전용량 2회 평판: C = εA/d → 면적에 비례, 간격에 반비례
면적 2배 → 정전용량 2배		 평판은 면적장사. "면비간반(面比間反)"
대전 현상 전자의 이동 때문에 +/− 전기를 띠는 현상
(에보나이트+천 마찰 = 대전 예시)		 움직이는 건 전자뿐. "전자만 굴러간다"
전기력선 성질 +에서 나와 −로 들어감 / 도체표면(등전위면)에 수직 출입 /
서로 교차 X / "등전위면과 방향 일치" → 틀림 (수직임) 		"등전위면=수직"만 기억. "등수직(等垂直)"
자성체 분류 강자성체(μ≫1) = 철(Fe)·니켈(Ni)·코발트(Co)
반자성체 = 구리(Cu)·금·은·납·아연·물
"강자성 아닌 것?" → 구리 (정답) 		철·니·코 만 강자성. "강자성=철니코(친구)"
교류 표현값 실횻값 = Vm/√2 / 평균값 = 2Vm/π ≒ 0.637Vm
최댓값 = 실횻값 × √2 (220V → 220√2 V)
파형률 = 실효/평균 ≒ 1.11 		220V 가정용 최댓값 ≒ 311V. "실루트2(實×√2)"
사인파 주파수·주기 V = 100sin(314t) → ω=314, f = 50 Hz, T = 0.02초
(ω = 2πf)		 314 보이면 50Hz 자동. "314 = 50Hz" (파이값!)

⚙️ 3. 전동기 · 변압기 · 3상

핵심 개념정답 (외울 핵심)한 줄 해설암기 팁 💡
Y-△ 기동법 목적 2회 기동전류를 1/3로 줄이기 위함 (전동기 소손·과부하 방지) 속도·전압 높이는 게 아님! "Y로 시작(↓), △로 달림"
동기속도 공식 2회 Ns = 120f/P [rpm]
예) 60Hz, 4극 → 120×60/4 = 1800 rpm		 주파수↑·극수↓ = 빠름. "백이공프피"(120f/P)
농형 유도전동기 2회 구조 간단·취급 용이 / VVVF 속도제어 가능 / 기동전류 큼
"슬립링에서 불꽃" → 틀림 (슬립링은 권선형에만 있음, 농형엔 없음!) 		농형=다람쥐 통(슬립링 X). "농(籠)에는 링이 없다"
유도전동기 일반 구조 간단·취급 용이·널리 사용되나 역률이 나쁜 결점 건물용 대부분 = 유도전동기. "흔하지만 역률꽝"
단상 유도전동기 대표 = 콘덴서 기동형
(분권·타여자 = 직류 / 권선형 = 3상)		 단상은 콘덴서. "단=콘"
변압기 철심 역할 3회 자속의 이동 통로 (1차 코일 자속을 2차 코일로 전달) 전기 흐르는 게 아니라 자속이 흐름. "철심=자속 고속도로"
단권 변압기 전압 2회 V₁/V₂ = N₁/N₂ → 100/V₂ = 100/60 → V₂ = 60 V 권수비 = 전압비. "권수=전압"
3상 교류 위상차 2회 평형 3상 각 상 간 위상차 = 120° (360°/3)
변압기 Y−△ 변환 시 1·2차 위상차 = 30°		 상간=120, Y△=30. "평형120 · 와이델30"
자기 에너지 (코일) W = ½ L I² [J]
예) L=4H, I=8A → ½×4×64 = 128 J		 전류 제곱에 비례. "반엘아이제곱"

💡 4. 조명 (광원 · 조명방식)

핵심 개념정답 (외울 핵심)한 줄 해설암기 팁 💡
할로겐램프 4회 휘도가 높다 (자동차 라이트로 사용)
흑화 거의 X / 백열보다 수명 김 / 광속·색온도 저하 적음
→ "휘도가 낮다" → 틀린 답 (정답!)
HID 램프에는 속하지 않음 (필라멘트 방식) 		자동차 헤드라이트 떠올리면 끝. "할로겐=자동차눈깔(밝음!)"
저압나트륨램프 3회 연색성이 가장 나쁨 (단일 노란 파장 → 색 구별 어려움)
→ 주로 터널조명에 사용 / "연색성 가장 우수" → 틀림 		효율은 최고, 색은 꽝. "터널=노란불=색 안 보임"
광속법 (조도계산) FUN = AED
F=광속, U=조명률, N=등개수, A=면적, E=조도, D=감광보상률
실내 전반조명 평균조도 계산법		 N = AED/FU "FUN한 AED"
조명수 계산 예) E=300lx, A=50, D=1.5, F=2500, U=0.5
N = (50×300×1.5)/(2500×0.5) = 18개		 공식 대입만 하면 됨. "위는 면조보, 아래는 광조"
조명률 영향요소 방의 크기 · 등기구 배광 · 천장·벽·바닥 반사율
→ "출입문 위치" → 영향 없음 (정답!)		 출입문은 무관. "문은 빛이랑 무관"
건축화 조명 종류 2회
  • 코너조명 : 천장·벽 경계 모서리에 등기구
  • 코브(코퍼)조명 : 홈을 파서 숨김, 간접 비춤
  • 광천장조명 : 천장 전체를 광원화 (확산판 부착)
  • 밸런스조명 : 천장·벽 균형있게
  • 코니스조명 : 벽면 상부 선반에 광원, 아래로 비춤
 위치별 이름 매칭이 포인트. "코너=모서리, 코브=홈, 광천장=면전체"
고휘도(HID) 램프 형광수은·고압나트륨·메탈할라이드 = HID
→ 할로겐은 HID 아님 (정답!)		 HID = 방전등. "할로겐은 필라멘트, HID는 방전"

🎛️ 5. 자동제어 · 시퀀스 · DDC

핵심 개념정답 (외울 핵심)한 줄 해설암기 팁 💡
피드백 제어 - 연속/불연속 5회 연속동작 = 비례(P) · 적분(I) · 미분(D) · 그 조합(PI/PD/PID)
불연속동작 = ON-OFF · 2위치 · 다위치 · 샘플링
→ "연속 아닌 것?" → 다위치·2위치·ON-OFF
→ "불연속 아닌 것?" → 비례·적분·미분 		PID계열은 무조건 연속. "피아디(P·I·D)=연속, 위치=불연속"
